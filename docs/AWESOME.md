## Contributing to this list

1. Fork the repository.
2. Add your entry to the relevant section in this file.
3. Keep descriptions short and honest — no marketing fluff.
4. Open a PR and link to the thing you are adding.

Please only add your own project if it is already usable by someone else, or clearly labeled as a work-in-progress experiment.
